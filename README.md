# PLBN Skouw — Scroll Animation

Website presentasi PLBN Skouw dengan animasi scroll. Berkas untuk GitHub Pages berada di `site/`. Workflow publikasi otomatis terdapat di `.github/workflows/pages.yml`.

## Galeri foto

GitHub Pages menyajikan halaman statis. Klik tag foto membuka galeri pada website asal, yang menyimpan foto di server. Login menggunakan akun yang memiliki akses website asal. Foto yang diunggah tidak dimasukkan ke repositori ini.

## Publikasi

Aktifkan Settings → Pages → Source: GitHub Actions. Push ke branch main menjalankan publikasi.
